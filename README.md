# HR Analytics Dashboard (Power BI)

## Overview

This project is an HR Analytics Dashboard built using Power BI to analyze employee data and gain insights into workforce trends.

## Objectives

* Analyze employee distribution across departments
* Understand attrition trends (Yes/No)
* Evaluate average salary
* Provide interactive filtering for better analysis

## Tools Used

* Power BI
* DAX (Data Analysis Expressions)
* Power Query

## Features

* Department-wise employee distribution (Bar Chart)
* Attrition analysis (Pie Chart)
* Average salary visualization (Card)
* Attrition rate calculation using DAX
* Interactive slicers for Department and Gender

## Key Insight

* The attrition rate in the dataset is 50%
